所有遊戲均支援單機。幼幼班包含現有電腦難度，並非所有線上玩法都開放幼幼班，例如小朋友下樓梯的對戰會排除該難度。彈珠籃球的電腦對手在房間提供。

同步修正你畫我猜的說明與詳情模式，移除已停用的電腦對戰／三段 AI；小朋友下樓梯徽章改為「生存」。中英文標籤逐一對應，卡片與詳情共用同一份資料。

驗證範圍為大廳的設定、翻譯、搜尋、分類、詳情及響應式顯示。未修改各獨立遊戲的規則，也未將來源核對視為全部遊戲完整對局測試。

## 驗證結果

- `npm run verify`：設定與 HTTP 路由測試、65 個翻譯 key、語言保存、英文遊戲資料檢查及 Pages 正式建置全部通過。
- Playwright Chromium：390×844、844×390、834×1112、1112×834、1440×900，各驗證繁中與英文，共 10 組。
- 每組核對全部 16 張卡片與 16 個玩法詳情的標籤；確認卡片標籤不溢出、頁面沒有水平溢出。
- 每組驗證幼幼班（11 款）、線上雙人（4 款）、觀戰（15 款）搜尋結果，以及三個分類、無結果狀態、設定開關與 Escape 返回。
- 語言重新載入後保存；瀏覽器沒有未處理 JavaScript 錯誤。截圖在 `verification/seo-shots/tags-*.png`（本機產物，不納入 Git）。
- 最後以一輪「核對來源 → 修正資料 → 測試與畫面驗證」複查；沒有改動遊戲規則或獨立遊戲畫面。
- `git diff --check` 與 UTF-8 無 BOM 檢查通過。
